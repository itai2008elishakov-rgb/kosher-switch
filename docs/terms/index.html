Terms of Use

Effective 2 October 2026

The short version: Kosher Switch is a free tool that helps make a phone kosher. Use it on phones you own or are responsible for, keep your code safe, and remember that no filter is perfect.

1. Agreeing to these terms

By using the Kosher Switch apps or this website, you agree to these terms. If you don't agree, please don't use them.

2. What Kosher Switch is

Kosher Switch turns a phone into a kosher phone: it limits which apps can be used, blocks or filters the internet, and needs a code to switch back. It is a tool, not a kashrut certification. Which apps are appropriate is up to you, your family, your school and your rav.

3. Use it on phones you're responsible for

  • Install Kosher Switch only on a phone you own, or one you're responsible for, like your child's phone.
  • Don't install it on another adult's phone without their clear agreement.
  • Don't use Kosher Switch to break the law or to harm anyone.

4. Your code and removing the app

Only the code you choose turns kosher mode off. Keep it somewhere safe: we can't recover it. On Android, Kosher Switch protects itself as the phone's “device owner”, so removing it requires a factory reset that erases the phone. Back up your phone before you set it up.

5. No guarantees

Kosher Switch is provided free and “as is”. We work hard to make it strong and reliable, but no filter or lock is perfect and we can't promise that nothing will ever get through, or that it will work on every phone. Parents remain responsible for how a phone is used.

Some features use other services, like weather, the family DNS filter and app stores. Their own terms apply to them. See the Privacy Policy for the list.
